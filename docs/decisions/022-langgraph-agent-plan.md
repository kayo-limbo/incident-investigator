# 普通 agent 的 LangGraph 迁移计划

日期：2026-10-31。状态：下一里程碑，尚未实现。本次方向调整基于本地代码与020/021交付记录，未新增框架API或依赖。

## 目标与边界

普通窗口 `agent` 的正式异步调查统一由图编排：模型决策 → 动作校验 → 工具执行 → 继续决策或结束。图实际控制各轮跳转，不把旧循环整体包进单个节点。校验和报告生成仍是普通 Python 领域函数，不要求每个辅助函数成为节点，也不需要引入假设策略的账本或额外接纳节点。

图状态保存版本、快照绑定、证据、用量、轮次、模型原始动作、已校验的待执行动作与报告；只保存可序列化数据。客户端、快照载荷、连接和本次单调时钟留在运行环境。CLI 和 Worker 使用同一套图节点及条件边，差别是 CLI 不配置 checkpointer，Worker 配置带租约隔离的 checkpointer。

复用模型适配器、证据工具、参数及引用校验、预算计算和报告结构。任务领取、心跳、尝试上限和最终结果落库继续属于任务层。同步普通调查、同步评测、旧单 Trace 入口和固定规则保持原执行范围。本阶段仅串行调查与恢复，不加入多 Agent、子图、并行分支、协议纠错或审批处置。

## 恢复契约

复用021的串行检查点机制，但必须给普通策略独立验收：

- `task_id` 绑定图执行，`run_token` 只证明本次租约；检查点访问与写入受任务行锁和有效租约约束，事务结束前重验。旧 Worker 失权后不能推进有效状态或写最终结果。
- 持久化完整步骤后再进入下一步。已提交的模型动作恢复后继续校验或执行工具，不重复发模型请求；待执行动作也须经过时限和执行前必要校验。
- 已提交证据、模型/工具调用、轮次及已知 token 跨重启累计；不能因重建 session 再收取一次摘要工具用量。首次开始的绝对截止时间保持不变，停机消耗时间预算。
- 模型调用前登记 `inflight_turn`，结果和用量提交时原子清除。恢复看到未确认调用则停止自动重发、返回 `usage_unavailable`，未知 token 不算零；不承诺外部调用 exactly-once。
- 工具执行后检查点未提交时，只允许重新执行现有只读冻结快照工具。最终报告已提交而任务终态未提交时补交终态，不再调用模型。
- 数据库故障传播到任务层，由租约接管裁决；不添加模型节点自动重试。检查点仍限受信任内部状态，不支持并行 pending writes、任意历史回放或人工修改。

CLI 仍使用单次运行的总时间预算，包含框架导入与快照读取；取消保留已有证据和实际发生的用量，并继续传播取消异常。仅 Worker 配置持久化时启用同步持久化参数，保留021已修复的无 checkpointer 入口行为。

## 实施顺序与验收

1. **图编排与无持久化入口。** 提取领域阶段、建立普通图、冻结旧异步对照。用相同脚本化动作比较成功、合理拒答、非法动作/引用、重复查询、模型错误、缺失快照、工具/token预算、未知用量、超时及取消。比较结论、证据内容和用量，只规范化耗时、随机证据ID与策略标识。验证真实节点顺序、JSON往返、校验后执行前取消、会话隔离及合法长循环。
2. **Worker 恢复。** 按策略选择恢复协议和图，普通 `agent` 接入租约检查点。用真实 PostgreSQL 和子进程强退验证：已提交决策不重发、未确认调用停止、工具重放、累计调用/token预算、停机耗时、终态补交、旧租约写入回滚及协议/请求不匹配拒绝。确保既有假设策略检查点仍可恢复。
3. **正式路径与回归。** 验证 CLI 无持久化与 Worker 有持久化确实使用同一图实现；正式分发不再引用旧普通异步循环，旧入口仅用于迁移对照。运行相关异步/预算/CLI/任务/恢复测试和全量回归，明确数据库项是否实际执行，随后更新实现与验证记录。

上述三个小交付共同完成本里程碑；仅完成第1项不能宣称普通 `agent` 已具备跨重启恢复。共享领域函数的新旧对照只证明编排一致性，还需独立领域断言与数据库验收。同步兼容入口不因本次验收而退出。

本轮仅完成代码核对和计划调整，未运行实现测试、真实模型或故障实验。后续串行图及恢复验收通过，也只能声明工程执行能力；诊断质量改善须另用固定协议和独立样本验证。
