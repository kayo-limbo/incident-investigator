# 细粒度工具与主动调查参考闭环

2026-11-10：实现独立`active-reference-v1`。这是有限假设域上的确定性参考执行器，先验证工具隔离、查询计划、状态更新与停止边界。尚未接真实LLM、异步模型预算、Worker恢复、普通ReAct或规划消融；不能描述为已验证的Agent增益。

## 工具和计划

输入只接收paired-bundle-v2安全快照，不读注入计划。初始告警计1次，默认总预算6，以下每次计1；工具单位费用不代表同等token或实际运行成本。

| 工具 | 可见内容 | 边界 |
| --- | --- | --- |
| get_window_summary | 单窗口独立字段P95、失败标记、样本量、最多3个慢请求ID | 不返回整窗请求、配置或入口速率 |
| get_request_trace | 已发现ID的单请求耗时、状态、错误类型 | 不接受任意ID；不返回配置；默认规划器不主动选此动作 |
| compare_runtime_config | 两窗口池容量与超时配置 | 不返回入口计数或速率 |
| compare_arrival_rate | 发送区间计数、时长、速率比、截止在途量 | 不返回池配置；不用排空时长算速率 |

Plan包含受限query、至少两个假设ID、gap和expected_outcomes。窗口摘要允许阶段枚举，配置比较仅允许decreased/unchanged/other/unavailable，入口比较仅允许increased/stable/other/unavailable。程序校验作用域、重复、缺口标识及完整预期分支；配置查询不能声明能判定入口变化。枚举校验不验证任意自然语言推理。

查询前校验全部完成才读取工具并记账，失败不改历史、不消耗工具预算。成功记录本次证据ID、实际分支、前后假设状态。外部策略可经`candidates()`读取计划并调用`execute(plan)`；首版未提供任意模型改写假设状态的接口，状态由已观测的有限条件推导。

## 状态与停止

假设固定为下游、容量、入口的观测变化，含open/supported/refuted/inconclusive、支持/反证的证据事件ID和缺口。引用是事件级，不是逐主张语义证明。配置下降不反驳入口增加，来源缺失不能作为反证，允许复合变化同时supported；这些状态不证明唯一根因。

候选查询的可解释分数为“相关open假设数＋补齐1个缺口－1次成本”，相同分数使用固定顺序；重复动作直接拒绝。首版仅给两窗口摘要和两类比较排序，请求下钻是供外部策略选择的验证接口，不宣称它改善诊断。缺口目前是这四类固定观察槽位，还不是任意自然语言问题分解。

停止原因包括sufficient、source_missing、unsupported_reference、conditions_not_met、budget_exhausted。健康两窗口且告警无失败时可提前结束；异常要求补齐配置和入口比较，再区分单变化与复合变化。无足够证据时保留已知stage并拒答。结束后的额外查询被拒绝。

## 开发回放与限制

```powershell
python -m evals.run_active_reference .snapshots/paired-20261109-development-v1 --output .snapshots/NEW_ACTIVE.private.json
python -m unittest discover -s tests -p 'test_active_investigation.py' -v
```

回放入口复用开发集标签检查和输入/源码指纹；拒绝heldout。仅向参考执行器传快照ID，不传场景标签或规则结论。本轮复用12份旧开发样本及24份派生视图，无新采集、无模型调用：

- 完整12份的类别符合预期；稳定/重启4份各3次工具，异常8份各5次，均含告警。
- trace_only：稳定/重启4份各3次给出无异常；其余8份各4次后拒答。任一比较工具明确缺少运行来源即停止，避免再查同源比较。
- runtime_only：12份各2次后因缺Trace拒答。

**真实差异保留**：旧规则允许缺Runtime时给出下游观测变化；本策略对这两份也拒答，因异常停止协议更保守。因此不能把与旧规则的查询差异当作主动规划收益。下一步需让强固定基线、普通ReAct、模型主动规划使用相同工具、证据权限、停止协议和预算，再进行规划/评分消融。当前排名启发式未证明比固定顺序更好。

8项新增专项覆盖未查询输入不影响状态、工具权限分离、错误预期原子拒绝、重复及未观测ID拒绝、五类结束、预算/缺失停止、缺失不作反证和结束后拒绝查询。整体语义验证、反例搜索、冲突样本以及任意假设生成均未实现。

全量首轮因本地测试PostgreSQL停止出现连接错误；启动原容器后345项重跑通过（178.061秒）。最后的缺失来源提前停止修改另作8项专项复验通过。最终开发报告为`.snapshots/active-reference-20261110-r2.private.json`，首版报告与失败日志保留；CLI帮助和暂存差异检查通过。
